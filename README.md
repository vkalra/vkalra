### Identity Federation Automation

Developed Python-based automation for provisioning and configuring
enterprise identity federation.

The automation creates and configures artifacts required for SAML
federation and SCIM integration between OCI Identity Domains and
enterprise identity providers, including Okta and Microsoft Entra ID.

**Technologies:** Python · SAML · SCIM · OCI IAM · OCI SDK ·
Okta · Microsoft Entra ID

[View project](https://github.com/vkalra/setupFed)

### OAuth 2.0 Device Code Flow

Implemented the OAuth 2.0 Device Authorization flow for an application
that could not directly collect a user's credentials.

The implementation obtains a device code, directs the user through
authentication, and polls the OAuth token endpoint until authorization
is completed.

**Technologies:** OAuth 2.0 · Device Authorization Grant · VBA · REST APIs

[View code](https://gist.github.com/vkalra/fc730a9862be21f6a847591b81cb2807)
